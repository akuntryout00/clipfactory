# Background music library

Drop royalty-free MP3s here named `<category>_NN.mp3`, e.g.

    upbeat_01.mp3
    productivity_soft_01.mp3
    minimal_01.mp3
    chill_01.mp3

Templates choose a `music_category`; the mixer picks a random track from that
category (falls back to any track, then to no music). Music is mixed ~-20 dB
under the voice with sidechain ducking.
